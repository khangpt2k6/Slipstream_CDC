# Slipstream

Slipstream is being rebuilt as a real-time, permission-aware enterprise search
engine (GitHub, Jira and Slack into one search). Work is in progress on `main`.

The previous version, a Postgres to ClickHouse CDC pipeline, is preserved at the
[`v1-cdc`](https://github.com/khangpt2k6/Slipstream_CDC/tree/v1-cdc) tag.
